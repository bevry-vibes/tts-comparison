7 · IPA input — real UTF-8 phonemes, not spelled-out sounds

You were right: the earlier test fed ASCII spellings ("shhh") and every engine tried to pronounce the letters. Harness research found proper phoneme input: Kokoro exposes generate_from_tokens() — raw IPA straight to the vocoder (≤510 chars); Piper accepts [[…]] blocks (espeak/IPA id map); Higgs has no phoneme path (LLM tokenizer — it received "ʃ" as plain text and improvised, loudly). All 13 Kokoro IPA clips verified as structured speech — including the five diphthongs that were TTS-only fallbacks and the AU ɜː.

9 · Phoneme sources — fixing the “phoneme-a-phoneme” sandwich

The Commons recordings wrap each phoneme in a vowel sandwich (e.g. “ʃ-a-ʃ”), which you find annoying. Three fixes compared: extracting the clean first consonant from the sandwich (energy-dip cut, works for sustained sounds — fricatives/nasals; plosives keep their release), and alternate speaker takes from Commons (484 files in the phonetic-samples category; several public domain, the rest CC BY-SA — both license-compatible). The extraction is deterministic, so it can run over all 35 bundled recordings automatically if this direction wins.
